Original procedural game sound effects generated by `scripts/generate-game-sfx.py`.
No recordings or third-party samples are used. These assets follow the repository's license.

Regenerate from the repository root with `python scripts/generate-game-sfx.py`.
Format: mono PCM WAV, 22,050 Hz, 16-bit. Total: 25 short effects.

The shared game mixer rotates match/swap/explosion variants, raises cascade pitch,
limits simultaneous voices and repeated impacts, and follows the sound volume setting.
